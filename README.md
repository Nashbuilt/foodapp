# Fresh Keep

A mobile-first food inventory single-page app built with plain HTML, CSS, and JavaScript.

## Features

- Add, edit, and remove food inventory items
- Store item names, expiry dates, locations, and notes
- Sort by expiry date, name, or storage location
- Filter all, expired, expiring soon, or fresh items
- Highlight expired and close-to-expiring foods
- Maintain a reusable common foods list
- Persist all app data in `localStorage`

## Deploy on Netlify

Deploy this folder directly:

```text
outputs/food-inventory-app
```

No build command is required. The publish directory is the project root.
